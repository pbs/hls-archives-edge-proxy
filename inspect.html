HLS Playlist Archives: edge inspector

Back to the player

See how the edge turns a live stream into playlists and archives, one request at a time.

  • The edge runs in this page. The same function that would run at the CDN reads the origin for real and writes every response you see.
  • Click any URI in a response to request it, the way a player would. ▸ at the end of a row shows what the edge fetched to answer, and ↻ asks again.
  • Watch the cache. Archives and tables are built once and then served from the cache. A refresh only reads the end of the live playlist.
  • Have an edge of your own? Give its .arch. URL and the page reads it directly. You see what a player gets, but not what the edge fetched to make it.
