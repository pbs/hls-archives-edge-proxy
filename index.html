HLS Playlist Archives

Inspect the edge

Hours of rewind on a live stream, with a live playlist that stays small.

  • The bar under the player is the rewind window. Each block is an archive, drawn where hls.js has it on the timeline. The green block at the end is the live playlist.
  • Seek back and watch them load. hls.js fetches an archive when playback needs it and lets go of the ones it no longer needs. The blue blocks are the ones it holds.
  • Try your own stream. Any live HLS stream from MediaPackage or Unified Origin with a DVR window works, if it allows cross-origin requests. The edge that makes the archives runs in this page. This demo assumes that a URL with .arch. in it already comes from an edge of its own, so hls.js plays it directly.

Playlist Archives (EXT-X-ARCHIVE) is an early proposal for HLS. This page runs an unofficial implementation: the edge function from hls-archives-edge-proxy turns the stream's DVR window into archives, and a build of hls.js with archive support plays them. In the console, hls.latestLevelDetails.archives shows what it has.
